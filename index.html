Case Study

Website Deals

Project overview.

Role UI Designer & Partner
Tools Figma
Status Client Project

01 — The challenge

Turning complexity into clarity.

The design process begins by understanding the people using the product and the goals behind the experience. The interface is then structured around the information users need most, helping important actions become easier to discover.

02 — The approach

Structure before styling.

Before polishing visual details, the experience is explored through content hierarchy, user flows and wireframes. This creates a stronger foundation for the final visual direction.

03 — The outcome

A more intentional experience.

The final direction balances usability and visual personality, creating an interface that communicates clearly while remaining flexible across screen sizes and future iterations.
